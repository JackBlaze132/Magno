Detailed Description

Initializer responsible for populating the database with all seedbed roles defined in the SeedbedRole enum at application startup.

This component checks for the existence of each role and creates any missing ones, ensuring the role table is always synchronized with the enum values.

Execution order: @Order(1) - Runs after EnumConstraintInitializer to ensure database constraints are updated before inserting roles.
