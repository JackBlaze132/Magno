Detailed Description

Helper interface for research seedbed student profile operations.

Why this helper exists: This helper is used to avoid circular dependencies between use cases. The ResearchSeedbedStudentProfileUseCase needs to interact with StudentProfile and AcademicPeriod services, which could create circular dependency chains. The helper encapsulates the logic for verifying and creating student profiles.

Responsibilities:

  • Verify that students have valid profiles in the academic period
  • Automatically create student profiles from Integra data when needed
  • Check academic period status for validation
