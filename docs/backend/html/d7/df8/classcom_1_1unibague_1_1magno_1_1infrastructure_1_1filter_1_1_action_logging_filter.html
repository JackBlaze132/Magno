Detailed Description

Servlet filter for auditing user actions.

Logs successful non-GET requests (POST, PUT, PATCH, DELETE) including request/response bodies and execution time. Runs late in the filter chain to capture complete responses. Logging is performed asynchronously to avoid impacting request performance.
