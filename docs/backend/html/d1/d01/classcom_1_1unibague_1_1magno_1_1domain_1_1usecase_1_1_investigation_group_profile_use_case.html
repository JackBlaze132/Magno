Detailed Description

Use case implementation for managing investigation group profiles.

Handles business logic for investigation group profile operations. An investigation group profile represents the state and configuration of an investigation group within a specific academic period, including its coordinator.

Why a helper is used: This use case delegates complex operations to IInvestigationGroupProfileHelper to avoid circular dependencies between use cases (e.g., this use case needs FunctionaryProfileServicePort, which might need this use case). The helper also encapsulates auxiliary logic for functionary profile management, keeping this use case focused on its core responsibilities.

Business rules enforced:

  • An investigation group can only have one profile per academic period
  • Only current (active) periods allow profile modifications
  • A user can only be coordinator of one investigation group per period
  • Profiles with associated research seedbed profiles cannot be deleted

Handles functionary profile deletion when an investigation group profile is deleted.

Since a user cannot be coordinator of more than one investigation group per academic period, and profiles cannot be deleted if they have associated research seedbed profiles, the functionary profile can be safely deleted when the investigation group profile is deleted.
