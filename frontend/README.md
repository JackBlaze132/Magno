# 🦅 Magno - Frontend Interface

This is the client-side application for the **Magno** Research Seedbeds Management System. Built with a modern tech stack to provide a responsive, intuitive, and performant experience for academic administrators and students.

## ✨ Frontend Highlights

- **⚡ Vite-Powered:** Instant Hot Module Replacement (HMR) and optimized build times.
- **🎨 Material Design:** Beautifully crafted with **Vuetify 3** and custom styling.
- **🛡️ Type-Safe:** Fully implemented in **TypeScript** for robust development.
- **🍍 Stateful:** Centralized state management using **Pinia** for authentication and data flow.
- **📱 Responsive:** Designed to work across tablets, laptops, and desktop monitors.

## 🛠️ Tech Stack

- **Vue 3** (Composition API)
- **Vuetify 3** (UI Components)
- **Pinia** (Global Store)
- **Vue Router** (SPA Navigation)
- **Vite** (Build Tool)
- **Remix Icon / Iconify** (Iconography)

## 🚀 Getting Started

### Installation

```bash
# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev
```
The application will be available at `http://localhost:3000` (by default).

### Production

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

## 📂 Architecture

- **`src/components/`**: Reusable UI parts (tables, forms, dialogs).
- **`src/stores/`**: Pinia stores for Auth and Global state.
- **`src/views/`**: Page-level components.
- **`src/plugins/`**: Vuetify, Router, and Pinia configuration.
- **`src/utils/`**: API handlers and formatting helpers.
