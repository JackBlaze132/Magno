Detailed Description

Use case implementation for managing users in the Magno system.

Handles business logic for user operations including CRUD operations, user type management (internal/external, student/functionary), and certificate generation. This is one of the most comprehensive use cases as users are central to the system.

Why a helper is used: This use case delegates DIRI user management to IUserHelper to encapsulate the specific logic of managing administrative users and their associated functionary profiles, keeping this use case focused on general user operations.

Key features:

  • Integration with Integra system for user data synchronization
  • Support for bulk user creation from Excel uploads
  • Student participation certificate generation
  • DIRI (administrative) user management
