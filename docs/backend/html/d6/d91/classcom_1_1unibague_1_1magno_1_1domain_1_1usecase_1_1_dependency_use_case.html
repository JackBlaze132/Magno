Detailed Description

Use case implementation for managing dependencies (organizational units).

Handles business logic for dependency operations. Dependencies represent organizational units within the university (faculties, departments) to which investigation groups and functionaries belong.

This use case integrates with the Integra system to automatically create dependencies that don't exist in the local database when searched by name.
