    Class LoadingManager

    Singleton LoadingManager class for tracking the loading state of multiple components. Manages component loading lifecycle and provides methods to track when all components are ready.

    LoadingManager

    Example

    import LoadingManager from '@/utils/loadingManager';

    // Set total components to track
    LoadingManager.setTotalComponents(5);

    // In each component's mounted/loaded hook
    LoadingManager.onChildLoaded();

    // Check if all loaded
    if (LoadingManager.allComponentsLoaded()) {
      console.log('All components ready!');
    }
