Detailed Description

Helper interface for research seedbed profile operations.

Why this helper exists: This helper is used to avoid circular dependencies between use cases and to encapsulate the complex logic of managing functionary profiles when coordinators or tutors change. The ResearchSeedbedProfileUseCase needs to interact with FunctionaryProfile, Role, Dependency, and other services, which could create circular dependency chains.

Responsibilities:

  • Verify and create functionary profiles for coordinators and tutors
  • Validate academic period status before operations
  • Handle role reassignment when coordinators/tutors change
  • Clean up orphaned functionary profiles when no longer needed

Handles functionary profile changes when a seedbed profile is updated or deleted.

When coordinators or tutors change, this method determines what to do with the old functionary profiles based on their usage across all seedbed profiles in the academic period:

  • If still an investigation group coordinator, keep their role
  • If still a seedbed coordinator elsewhere, update to COORDINADOR_DE_SEMILLERO
  • If only a tutor elsewhere, update to TUTOR_DE_SEMILLERO
  • If not used anywhere, delete the functionary profile
Parameters
researchSeedbedProfilescurrent list of seedbed profiles in the academic period (after update/delete)
academicPeriodIdthe ID of the academic period
oldCoordinatorIdthe ID of the previous coordinator's functionary profile
oldTutorIdthe ID of the previous tutor's functionary profile (can be null)

ResearchSeedbedProfile com.unibague.magno.domain.usecase.helper.IResearchSeedbedProfileHelper.verifyUsersHasFunctionaryProfiles ( ResearchSeedbedProfile rsp)

Verifies that both coordinator and tutor have valid functionary profiles.

If a functionary profile doesn't exist for the coordinator or tutor in the specified academic period, one is automatically created with the appropriate role and dependency information from Integra.

Role assignment logic:

  • Coordinator receives COORDINADOR_DE_SEMILLERO role
  • Tutor receives TUTOR_DE_SEMILLERO role
  • Existing profiles may have their roles upgraded if needed
Parameters
rspthe research seedbed profile containing coordinator, tutor, and period information
Returns
the updated research seedbed profile with functionary profile IDs set
