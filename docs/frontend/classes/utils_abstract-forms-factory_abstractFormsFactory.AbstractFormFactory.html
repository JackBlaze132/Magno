    Class AbstractFormFactoryAbstract

    Abstract base class for form factories. Concrete factories should extend this class and implement getComponentConfig to return a component and its props for a given entity type and action.

    This class also provides a helper getDefaultComponent that returns a placeholder Vue component to render when no matching component is found for a requested type.

    AbstractFormFactory

    Example

    // Example implementation in a concrete factory
    class MyCreateFactory extends AbstractFormFactory {
      getComponentConfig(type) {
        if (type === 'period') {
          return { component: CreatePeriodComponent, props: { /* ... */ } };
        }
        return this.getDefaultComponent();
      }
    }
