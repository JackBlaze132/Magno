Detailed Description

Service for handling authorization checks related to research seedbed profiles.

Validates whether the current user has permission to perform actions on specific research seedbed profiles based on their role or coordinator status.

void com.unibague.magno.infrastructure.configuration.security.ResearchSeedbedProfileAuthorizationService.validateCanModifyResearchSeedbedProfile ( Long researchSeedbedProfileId,
CurrentUserInfo currentUserInfo )

Validates that the current user can modify the specified research seedbed profile.

Authorization is granted if the user:

  • Has DIRI role (global admin)
  • Is the coordinator of the research seedbed profile
  • Is the coordinator of the investigation group that contains the seedbed
Parameters
researchSeedbedProfileIdthe ID of the research seedbed profile
currentUserInfothe current authenticated user info
Exceptions
NotAllowedToDoThisActionExceptionif the user is not authorized
ResearchSeedbedProfileNotFoundExceptionif the profile does not exist
