Detailed Description

REST controller for managing research seedbed profiles in Magno.

Provides endpoints for CRUD operations on research seedbed profiles, which represent the state and configuration of a research seedbed for a specific academic period. Also includes endpoints for generating Excel reports on individual seedbed activities.
