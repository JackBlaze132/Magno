Detailed Description

REST client implementation of IIntegraPersistencePort for fetching data from the external Integra system.

This class is a critical component of the Magno system as it serves as the primary integration point with the University of Ibagué's central information systems. It connects to:

  • Integra API: The main university system for functionaries, students, and dependencies
  • Academia API: The academic system for program information (undergraduate and postgraduate)

All HTTP communications are performed using RestTemplate with SSL certificate validation disabled (configured in RestTemplateConfiguration) to handle the university's self-signed certificates.

Important: This client requires a valid API token (integraApiToken) for authentication with the Integra system. Unauthorized requests will result in HTTP 401 errors.

Map< AcademicProgramType, List< IntegraAcademicProgram > > com.unibague.magno.infrastructure.output.jpa.adapter.integra.IntegraUserClient.getAllAcademicProgramsMappedByType ( )

Retrieves all academic programs from both Integra and Academia sources, organized by program type.

This method consolidates academic program data from multiple sources and categorizes them:

  • PREGRADO (Undergraduate): Programs from Integra + Academia undergraduate endpoint
  • POSGRADO (Postgraduate): Programs from Academia postgraduate endpoint

Deduplication is performed to ensure each program code appears only once:

  • Within undergraduate: first occurrence is kept
  • For postgraduate: programs already in undergraduate are excluded
Returns
a map where keys are AcademicProgramType (PREGRADO or POSGRADO) and values are lists of unique IntegraAcademicProgram objects
Exceptions
NullIntegraResponseExceptionif any of the API calls returns a null response body
org.springframework.web.client.RestClientExceptionif there's a communication error with any API
