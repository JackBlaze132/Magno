    Class LogService

    Singleton LogService class for fetching and managing application logs. Provides methods to retrieve ACTION, CRONJOB, and ERROR logs with various filtering options.

    LogService

    Example

    import LogService from '@/utils/logService';

    // Fetch action logs by user ID
    const logs = await LogService.fetchLogs('ACTION', { userId: '123' });

    // Fetch cronjob logs by date range
    const cronLogs = await LogService.fetchLogs('CRONJOB', {
      startDate: '2024-01-01T00:00:00',
      endDate: '2024-12-31T23:59:59'
    });
