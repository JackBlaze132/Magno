Detailed Description

Use case implementation for enum-related operations.

Provides utility methods for working with enums in the Magno system, including retrieving formatted enum values and validating enum membership.

Note: Enums used with this service must implement a getFormattedName() method that returns a human-readable string representation of the enum value.
