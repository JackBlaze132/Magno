    Class API

    Singleton API class for managing HTTP requests to the backend. Provides methods for GET, POST, PUT, DELETE operations and handles authentication. All endpoints are defined as public properties for easy access throughout the application.

    API

    Example

    import API from '@/utils/api';

    // GET request
    const users = await API.get(API.USERS, {'API-VERSION': '1'});

    // POST request
    const newUser = await API.post(API.USERS, userData);
