Checks if the academic period is NOT in current status.

This is used to validate that operations can only be performed on active academic periods.

Parameters
academicPeriodIdthe ID of the academic period to verify
Returns
true if the academic period is NOT current (operations should be blocked), false if the academic period IS current (operations are allowed)
